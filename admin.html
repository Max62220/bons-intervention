Sauvegarde chiffrée sur GitHub

La liste est chiffrée sur ce poste avec votre mot de passe, puis enregistrée automatiquement dans le dépôt GitHub de l'appli (fichier sauvegarde/techniciens.enc) à chaque modification. Le fichier est visible publiquement mais illisible sans le mot de passe.

La sauvegarde utilise votre mot de passe administrateur. Il n'est jamais enregistré ni envoyé : sans lui, la sauvegarde est illisible, y compris pour vous.

Historique des techniciens : jeton « Issues »

Second jeton GitHub, transmis dans les liens des techniciens : limité à ce dépôt et à la permission Issues : Read and write (aucun accès aux fichiers de l'appli). Les tickets (Issues) doivent être activés sur le dépôt.

Lien à transmettre

Remplissez le formulaire puis cliquez sur « Créer le lien ». Le technicien l'ouvre sur son téléphone : ses réglages se remplissent tout seuls.

Créer un bon avec ce profil

Ouvre l'appli dans un nouvel onglet, configurée pour ce technicien (votre navigateur garde ensuite ce profil jusqu'au prochain).

Importer depuis Excel

Dans Excel, sélectionnez les lignes avec la ligne d'en-tête (par ex. colonnes F à M de l'onglet « Clients » de la Base article), copiez, puis collez ici. Colonnes reconnues : code client (BP Sold to), nom (BP Sold to Name1), rue (Street), n° (Haus Number), code postal (Post Code), ville (City), département, contact, e-mail. Sans en-tête, l'ordre attendu est : code, nom, rue, code postal, ville.
